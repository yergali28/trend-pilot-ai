# Trend Pilot AI: правила для Claude Code

Полное ТЗ: `docs/TZ.md`. При конфликте этого файла и ТЗ спроси владельца, не выбирай сам.

## Что строим
SaaS для селлеров маркетплейсов (Kaspi, Ozon, Wildberries). Пользователь выбирает, где продаёт и где закупает, бюджет и кратность (2x/3x/5x/10x). Система возвращает категории и товары с юнит-экономикой. Рынок v1: Казахстан и Россия (KZT, RUB). Языки: RU, EN, KZ.

## Структура (монорепо, pnpm + Turborepo)
- `apps/web`: Next.js (App Router) + TypeScript + Tailwind
- `apps/worker`: загрузка и обработка данных, очередь `pg-boss`
- `packages/calc`: ядро расчёта юнит-экономики
- `packages/adapters/*`: адаптеры источников
- `packages/db`: миграции Supabase и типы
- `packages/ui`: дизайн-система и компоненты
- `fixtures/`: записанные ответы источников, `calc-golden-cases.json`

## Команды
`pnpm run setup`, `pnpm db:start`, `pnpm db:reset`, `pnpm dev`, `pnpm test`, `pnpm test:e2e`, `pnpm lint`, `pnpm typecheck`, `pnpm build`. Задача не завершена, пока `lint`, `typecheck` и `test` не прошли, а их вывод не показан в разговоре.

## Жёсткие правила
1. **Только реальные данные.** Не придумывай числа: ни цен, ни комиссий, ни тарифов, ни продаж. Нет данных значит статус `no_data`. Статусы значений: `verified`, `estimated`, `no_data`.
2. **У каждого значения есть источник, время получения и статус достоверности.** Значение без источника не выводится в интерфейс.
3. **Формулы только в `packages/calc`.** Расчёт детерминированный. LLM никогда не генерирует числа, только объясняет уже рассчитанные.
4. **Синтетические данные** (`synthetic: true`) разрешены только в тестах и демо-режиме, никогда не попадают в справочники и не показываются как рыночные.
5. **Секреты.** Не коммить `.env*` кроме `.env.example`. Токены не логировать. Боевые токены не использовать в `local`, `preview`, `staging`. Исключение (решение владельца 19.10.2026): персональный боевой токен Wildberries только для чтения (`WB_API_TOKEN` в `apps/worker/.env.local`) разрешён в `local` и `staging` для записи ответов и проверки адаптера; тестового контура у кабинета нет. Подробности и рамки: `docs/sources/wildberries.md`.
6. **Адаптеры имеют режимы** `live`, `replay`, `mock`. В `local` по умолчанию `replay`. Новые источники включаются через `data_sources.status`.
7. **Не обходи капчу, защиту и правила площадок.** Сбор публичных страниц не включать без письменного решения владельца после юридической проверки.
8. **Не ставь сторонние пакеты и не скачивай внешний код без необходимости.** Исключение: инструменты и `npx impeccable install` из этапа 0 в `docs/GOALS.md`. Homebrew скриптом из интернета не ставить, пароли не вводить. Если что-то требует действия владельца, остановись и скажи.
9. **Изоляция организаций.** Каждая таблица с данными клиента имеет `org_id` и политики RLS. На них есть автоматические тесты.
10. **Работай в ветке**, не в `main`. Коммит после каждого завершённого шага. Миграции обратимы или совместимы с прошлой версией.
11. **Не создавай аккаунты, не регистрируйся на сервисах, не отправляй письма и сообщения** от имени владельца. Если нужен токен или аккаунт, остановись и перечисли, что требуется.

## Дизайн
Источник: Impeccable. Минимализм, акцентные цвета с ролями, светлая тема по умолчанию. Значения (палитра, шрифты, отступы) берутся только из design tokens проекта. Запрещены градиенты, одинаковые карточки с мягкими тенями, эмодзи вместо иконок, декоративные анимации. Перед завершением экрана: `critique`, `audit`, `polish`, затем `npx impeccable detect apps/web packages/ui` без находок.

## Язык
Код и имена на английском. Тексты интерфейса через i18n-ключи (ru, en, kk), ни одной строки интерфейса в коде напрямую. Документация и комментарии к решениям на русском.

## Как докладывать
В конце каждого этапа: что сделано, какие команды проверки запущены и их вывод, что не удалось, какие данные или токены нужны от владельца.
