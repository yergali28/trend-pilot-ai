# Команды /goal для Trend Pilot AI

## Как запускать
1. Требуется Claude Code v2.1.139 или новее. Проверка: `claude --version`.
2. Открой Claude Code в папке проекта `/Users/yergalizhakhan/WebProjects/trend-pilot-ai`. В неё уже положены `CLAUDE.md`, `docs/TZ.md` и `docs/GOALS.md`.
3. Включи auto mode. Начни с этапа 0, он ставит инструменты и подключает репозиторий.
4. Вставляй текст цели целиком. Оценщик видит только разговор, поэтому в условиях требуется показывать вывод команд.
5. Этапы идут строго по порядку. Следующий начинай после того, как проверил результат предыдущего и слил ветку.
6. Если цель остановилась по лимиту ходов, это нормально: запусти её снова, она продолжит с места остановки.
7. Если цель остановилась и просит пароль администратора macOS или вход в GitHub, выполни это сам и запусти цель снова: пароли Claude Code не вводит.
