# Дизайн-система Trend Pilot AI

Статус: **на согласовании у владельца**. Экраны продукта не верстаются, пока палитра и UI-kit не утверждены.

- Единственный файл токенов: [`packages/ui/tokens.css`](../packages/ui/tokens.css). Значения в коде берутся только оттуда, через утилиты Tailwind (`bg-surface`, `text-muted`, `border-line`, …) или CSS-переменные `--tp-*`.
- Компоненты: [`packages/ui/src`](../packages/ui/src). Тексты в компоненты приходят через props из i18n приложения (`apps/web/messages/{ru,en,kk}.json`).

- Машиночитаемая версия для Impeccable: `apps/web/DESIGN.md` и `apps/web/.impeccable/design.json`.

## Направление

Стандарт категории, исполненный на уровне Stripe Dashboard и MPStats (решение владельца, 18.10.2026). Нейтральная база, один акцент действия, шкала кратности и статусы с ролями. Цвет всегда несёт смысл и дублируется словом или формой. Светлая тема по умолчанию, тёмная вторая (переключатель в настройках).

Запрещено: градиенты, одинаковые карточки с мягкими тенями, вложенные карточки, эмодзи вместо иконок, декоративные анимации, кикеры над заголовками.

### Шкала кратности 2x → 10x

Чем выше кратность, тем насыщеннее зелёный. Значение всегда подписано числом (`3,6x`), цвет только дублирует его.

| Ступень | Токены | Светлая (фон / текст) | Тёмная (фон / текст) |
|---|---|---|---|
| ниже 2x | `--tp-x-below-*` | `#eef0f3` / `#4a5361` | `#232a33` / `#b3bac5` |
| от 2x | `--tp-x2-*` | `#dcf1e4` / `#1a5e3c` | `#16352a` / `#9fe3bf` |
| от 3x | `--tp-x3-*` | `#a8dcbf` / `#0f4a2d` | `#1f5a40` / `#d2f5e2` |
| от 5x | `--tp-x5-*` | `#21804e` / `#ffffff` | `#3fb57a` / `#06140d` |
| от 10x | `--tp-x10-*` | `#0e5132` / `#ffffff` | `#8ee0b5` / `#06140d` |

Метрика кратности переключается (цена ÷ себестоимость по умолчанию или ROI); шкала одна для обеих.

### Данные

Данные нейтральные: синий остаётся только за действием. Цвет в графиках появляется, только когда несёт смысл (прибыль, убыток).


| Роль | Токен | Светлая | Тёмная |
|---|---|---|---|
| Линия спарклайна | `--tp-chart-line` | `#4a5361` | `#b3bac5` |
| Waterfall: цена | `--tp-chart-total` | `#4a5361` | `#b3bac5` |
| Waterfall: расход | `--tp-chart-decrease` | `#c9ced6` | `#3a4350` |
| Waterfall: прибыль / убыток | `--tp-chart-result` / `--tp-chart-loss` | `#21804e` / `#b42318` | `#3fb57a` / `#ff8f84` |

Контраст: текст ≥ 4,5:1 к фону в обеих темах (проверено детектором Impeccable на живой странице; фактические коэффициенты для каждой пары показаны на `/design`). Минимум в светлой теме 4,8:1 (источник отключён), в тёмной 6,0:1.

Убыток: прибыль цветом риска с иконкой и скрытым словом «убыток» для экранного диктора.

## Типографика

**Golos Text** (Google Fonts, раздаётся самим приложением через `next/font`), наборы Latin, Cyrillic, Cyrillic Ext: покрывает русский, английский и казахский (ә ғ қ ң ө ұ ү һ і). Шрифт с кириллицей как основой, у него настоящие табличные цифры (`tabular-nums`: все цифры одной ширины).

| Шаг | Размер / интерлиньяж | Начертание | Роль |
|---|---|---|---|
| `2xl` | 32 / 40 | 600 | заголовок экрана |
| `xl` | 24 / 32 | 600 | заголовок раздела |
| `lg` | 20 / 28 | 600 | заголовок карточки |
| `md` | 16 / 24 | 400–600 | ключевые числа в карточке |
| `base` | 14 / 22 | 400–500 | основной текст, таблицы, поля |
| `sm` | 13 / 20 | 400–500 | подписи, заголовки колонок, подсказки |
| `xs` | 12 / 16 | 400 | только служебное, не для текста |

Числа: всегда `tabular-nums`, в таблицах выравнивание вправо по разряду, валюта и единица рядом со значением (`10 000 ₸`, `3,6x`, `91 %`). Формат чисел по локали (`Intl.NumberFormat`), символ валюты узкий (`₸`, `₽`). Оценочное значение помечается «≈», отсутствующее — словом «нет данных».

## Отступы, радиусы, слои

- Шаг 4px: `1 = 4px, 2 = 8px, 3 = 12px, 4 = 16px, 6 = 24px, 8 = 32px, 12 = 48px, 16 = 64px`. Плотно внутри группы, просторно между группами, над заголовком больше места, чем под ним.
- Радиусы: `--radius-control` 6px (кнопки, поля, чипы, бейджи), `--radius-panel` 8px (таблица, карточка, пустое состояние), 4px у мелких меток (квадрат чекбокса, столбцы waterfall).
- Тени: только у всплывающих слоёв (`--shadow-overlay`). Панели отделяются линиями и фоном, без теней.
- Высота контролов: 36px (`h-9`), компактная кнопка 32px; на сенсорных экранах (`pointer: coarse`) 44px.

## Компоненты (`@tp/ui`)

| Компонент | Назначение |
|---|---|
| `Button` | основная, вторичная, текстовая; состояния disabled и loading (`aria-busy`) |
| `TextField`, `SelectField` | поле с подписью, подсказкой, ошибкой (`aria-invalid`, `aria-describedby`), суффикс валюты |
| `MarketplacePicker` | мультивыбор площадок с режимом «Все»; «Все» включает только активные источники; неактивная площадка серая с причиной |
| `DataTable` | числа справа, табличные цифры, закреплённая первая колонка; текущая сортировка показана иконкой и `aria-sort`, само переключение подключается на экранах с данными |
| `ProductCard` | факты товара, бейдж кратности, раскрытие «Почему так?» (`details`) |
| `MultipleBadge` | ступень шкалы 2x/3x/5x/10x с подписью значения |
| `Sparkline` | динамика цены в ячейке таблицы, `role="img"` с подписью |
| `Waterfall` | юнит-экономика от цены продажи до чистой прибыли; шаги считает `waterfall()` из `@tp/calc` |
| `SourceStatus` | статус источника: форма + цвет + слово + причина |
| `CoverageBadge` | «Данные с N из M площадок» |
| `StatusTag`, `NoData`, `Value` | статусы риск / предупреждение / нет данных / оценка |
| `EmptyState` | что произошло и что сделать дальше |

Все расчёты юнит-экономики только в `packages/calc`; компоненты показывают готовые значения и их статус.

## Тексты и голос

На «вы», коротко и по делу, как финансовый инструмент. Без восклицаний и маркетинга. Ошибка называет проблему и способ исправить («Введите число больше нуля»). Все тексты через i18n-ключи ru, en, kk; казахский перевод проверяется вручную.

## Доступность

WCAG AA: контраст текста ≥ 4,5:1, видимый фокус (`outline` цвета `--tp-focus`), полная клавиатурная навигация, подписи у всех полей, статус не только цветом. Анимации только функциональные (загрузка, раскрытие), с учётом `prefers-reduced-motion`.
